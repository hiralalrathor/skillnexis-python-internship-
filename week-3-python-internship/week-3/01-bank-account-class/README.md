# Bank Account Class

**Assignment:** Create a class with methods: deposit, withdraw, display balance.

An object-oriented bank account simulator. The `BankAccount` class
encapsulates the account holder's name and balance, with methods to
deposit, withdraw, and display the current balance.

## Concepts Used
- Classes and objects
- Constructors (`__init__`)
- Instance methods
- Input validation

## How to Run
```bash
python bank_account.py
```

## Example
```
=== Bank Account Class Demo ===
Enter account holder name: Aarav
=== Bank Account ===
1. Deposit
2. Withdraw
3. Display Balance
4. Exit
Choose an option (1-4): 1
Enter amount to deposit: 1000
Deposited ₹1000.00. New balance: ₹1000.00
```
