# Calculator Class with Exception Handling

**Assignment:** Calculator Class with Exception Handling.

A `Calculator` class that performs the four basic arithmetic
operations, with proper exception handling for invalid input and
division by zero.

## Concepts Used
- Classes and methods
- Custom exception raising (`raise ZeroDivisionError`)
- Exception handling (`try`/`except`)

## How to Run
```bash
python calculator_class.py
```

## Example
```
=== Calculator Class with Exception Handling ===
Operations: +, -, *, /
Enter the first number: 10
Enter an operator (+, -, *, /): /
Enter the second number: 0
Error: Cannot divide by zero.
```
