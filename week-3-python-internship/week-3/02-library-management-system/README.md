# Library Management System (OOP)

**Assignment:** Add/remove books, issue/return books.

An object-oriented library system with two classes: `Book`
(represents a single book) and `Library` (manages the collection).
Supports adding, removing, issuing, and returning books.

## Concepts Used
- Classes and objects (two related classes)
- Object composition (`Library` holds a list of `Book` objects)
- Instance methods
- Loops and menus

## How to Run
```bash
python library_management.py
```

## Example
```
=== Library Management System ===
1. Add Book
2. Remove Book
3. Issue Book
4. Return Book
5. View All Books
6. Exit
Choose an option (1-6): 1
Enter book title: The Alchemist
Enter author name: Paulo Coelho
Book 'The Alchemist' by Paulo Coelho added.
```
