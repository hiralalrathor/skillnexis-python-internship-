# Mini Project Task: Contact Book (Dictionary-based)

**Assignment:** Build a Contact Book app using dictionary.

Stores contacts (name, phone, email) in a Python dictionary, with
add, view, search, and delete functionality.

## Concepts Used
- Dictionaries (nested — each contact stores phone + email)
- Functions
- Loops and menus

## How to Run
```bash
python contact_book.py
```

## Example
```
=== Contact Book ===
1. Add Contact
2. View All Contacts
3. Search Contact
4. Delete Contact
5. Exit
Choose an option (1-5): 1
Enter contact name: Riya
Enter phone number: 9876543210
Enter email: riya@example.com
Contact 'Riya' added.
```
