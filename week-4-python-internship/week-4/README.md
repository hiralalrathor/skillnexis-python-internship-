## How to Run Any Project
1. Make sure Python 3 is installed: `python --version`
2. Navigate into the project folder, e.g. `cd 01-capstone-employee-data-analysis`
3. Install any dependencies noted in that folder's README
4. Run the script, e.g. `python employee_analysis.py`

## Note on Network-Based Projects
The Weather App and Crypto Price Fetcher require live internet
access and, for the Weather App, a free API key — they were written
and reviewed for correctness but could not be live-tested in this
environment. The Email Automation Tool defaults to a safe dry-run
mode so it can be tested without sending real emails.
