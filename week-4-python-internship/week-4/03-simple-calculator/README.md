# Mini Project Task: Simple Calculator (Functions)

**Assignment:** Create a simple calculator using functions.

A command-line calculator built entirely with standalone functions
(no classes) — addition, subtraction, multiplication, and division.

## Concepts Used
- Functions
- Conditional statements
- Exception handling

## How to Run
```bash
python simple_calculator.py
```

## Example
```
=== Simple Calculator (Functions) ===
Operations available: +, -, *, /
Enter the first number: 12
Enter an operator (+, -, *, /): *
Enter the second number: 4
Result: 48.0
```
