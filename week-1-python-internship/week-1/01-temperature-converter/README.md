# Temperature Converter

**Assignment:** Convert Celsius ↔ Fahrenheit using functions.

A command-line program that converts a temperature value between
Celsius and Fahrenheit, based on the user's chosen direction.

## Concepts Used
- Functions
- Conditional statements
- User input and type conversion

## How to Run
```bash
python temperature_converter.py
```

## Example
```
=== Temperature Converter ===
1. Celsius to Fahrenheit
2. Fahrenheit to Celsius
Choose an option (1 or 2): 1
Enter the temperature value: 100
100.0°C = 212.00°F
```
