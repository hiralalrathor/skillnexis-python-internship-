# Student Grade Calculator

**Assignment:** Take marks as input, calculate average & assign grades.

Takes marks for any number of subjects, calculates the average, and
assigns a letter grade based on standard grading bands.

## Grading Scale
| Average | Grade |
|---------|-------|
| 90-100  | A     |
| 80-89   | B     |
| 70-79   | C     |
| 60-69   | D     |
| 40-59   | E     |
| Below 40| F     |

## Concepts Used
- Functions
- Lists
- Loops
- Conditional statements

## How to Run
```bash
python grade_calculator.py
```

## Example
```
=== Student Grade Calculator ===
Enter the number of subjects: 3
Enter marks for subject 1 (0-100): 85
Enter marks for subject 2 (0-100): 92
Enter marks for subject 3 (0-100): 78

Marks entered: [85.0, 92.0, 78.0]
Average: 85.00
Grade: B
```
