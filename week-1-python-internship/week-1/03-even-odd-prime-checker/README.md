# Even/Odd & Prime Number Checker

**Assignment:** Check whether a number is Even/Odd and whether it is Prime.

Takes a whole number as input and reports whether it is even or odd,
and whether it is a prime number.

## Concepts Used
- Functions
- Loops
- The modulus operator
- Conditional logic

## How to Run
```bash
python even_odd_prime_checker.py
```

## Example
```
=== Even/Odd & Prime Number Checker ===
Enter a whole number: 17
17 is Odd.
17 is Prime.
```
