# Week 1 – Python Programming Internship (Skill Nexis)

**Skill Gain:** Loops, conditionals, modular programming.

This folder contains the Week 1 assignments and mini project for the
Skill Nexis Python Programming Internship.

## Assignments

| # | Project | Description |
|---|---------|-------------|
| 1 | [Temperature Converter](./01-temperature-converter) | Convert Celsius ↔ Fahrenheit using functions |
| 2 | [Student Grade Calculator](./02-student-grade-calculator) | Take marks as input, calculate average & assign grades |
| 3 | [Even/Odd & Prime Number Checker](./03-even-odd-prime-checker) | Check if a number is even/odd and whether it's prime |

## Mini Project

| Project | Description |
|---------|-------------|
| [Simple ATM Simulator](./04-atm-simulator-mini-project) | PIN-based login, check balance, deposit, withdraw — using functions for each operation |

## How to Run Any Project
1. Make sure Python 3 is installed: `python --version`
2. Navigate into the project folder, e.g. `cd 01-temperature-converter`
3. Run the script, e.g. `python temperature_converter.py`
