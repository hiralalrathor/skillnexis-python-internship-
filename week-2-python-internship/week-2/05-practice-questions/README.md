# Practice Questions — Week 2: Data Structures & Loops

Five standalone practice scripts covering lists, dictionaries,
nested loops, and sorting.

| # | File | Question |
|---|------|----------|
| 1 | `q1_list_crud.py` | Create a list and perform CRUD operations |
| 2 | `q2_word_frequency.py` | Write a dictionary program to count word frequency |
| 3 | `q3_pattern_printing.py` | Use nested loops to print a pattern |
| 4 | `q4_largest_smallest.py` | Find largest and smallest number in a list |
| 5 | `q5_sort_with_lambda.py` | Sort a list using `sort()` and a lambda key |

## How to Run
```bash
python q1_list_crud.py
python q2_word_frequency.py
python q3_pattern_printing.py
python q4_largest_smallest.py
python q5_sort_with_lambda.py
```
