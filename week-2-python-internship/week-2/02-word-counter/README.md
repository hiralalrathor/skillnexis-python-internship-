# Word Counter from Text File

**Assignment:** Count number of words, lines, and characters.

Reads a text file and reports how many lines, words, and characters
it contains. A sample file (`sample.txt`) is included for testing.

## Concepts Used
- File I/O (reading files)
- String methods (`.split()`)
- Exception handling (missing file)
- Functions

## How to Run
```bash
python word_counter.py
```
When prompted, enter `sample.txt` to test with the included file.

## Example
```
=== Word Counter from Text File ===
Enter the path to a text file (e.g. sample.txt): sample.txt

File: sample.txt
Lines: 4
Words: 39
Characters: 250
```
