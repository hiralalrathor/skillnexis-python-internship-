# JSON File Reader

**Assignment:** Load JSON data & print formatted output.

Reads student data from a JSON file and displays it in a neatly
formatted table. A sample file (`sample_data.json`) is included.

## Concepts Used
- The `json` module
- File I/O
- Exception handling (missing file, invalid JSON)
- String formatting

## How to Run
```bash
python json_reader.py
```
When prompted, enter `sample_data.json` to test with the included file.

## Example
```
=== JSON File Reader ===
Enter the path to a JSON file (e.g. sample_data.json): sample_data.json
Name           Roll No.    Marks     
-----------------------------------
Aarav          101         88        
Isha           102         92        
Kabir          103         76        
```
