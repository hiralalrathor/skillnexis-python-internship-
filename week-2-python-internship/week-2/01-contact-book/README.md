# Contact Book using Dictionary

**Assignment:** Add, search, update, delete contacts.

A command-line contact book that stores names and phone numbers in a
Python dictionary, with full CRUD (Create, Read, Update, Delete)
functionality.

## Concepts Used
- Dictionaries
- Functions
- Loops and menus
- Conditional statements

## How to Run
```bash
python contact_book.py
```

## Example
```
=== Contact Book ===
1. Add Contact
2. Search Contact
3. Update Contact
4. Delete Contact
5. View All Contacts
6. Exit
Choose an option (1-6): 1
Enter contact name: Riya
Enter phone number: 9876543210
Contact 'Riya' added.
```

## Note
Contacts are stored in memory only for this session (no file
persistence) — see the Week 2 mini project for a version that saves
data permanently.
